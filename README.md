# DOAJ Scraper

Програма збирає інформацію про всі журнали з каталогу DOAJ (doaj.org) і зберігає її в базу SQLite,
а також завантажує HTML-сторінку кожного журналу (`https://doaj.org/toc/{issn}`).

## Як працює

1. **Етап 1 — журнали.** Програма робить той самий запит, що й сторінка пошуку DOAJ
   (`/query/journal/_search`, знайдено у DevTools → Network), по 100 журналів за раз.
   Гортання — через `search_after` Elasticsearch, бо звичайне гортання обмежене 10 000 результатів.
2. **Етап 2 — сторінки журналів.** Для кожного журналу береться `eissn` (або `pissn`, якщо `eissn` нема),
   і сторінка `/toc/{issn}` зберігається як `.html`.

Між запитами — пауза ~1 с. На помилки й перевірку Cloudflare програма відповідає повторами з
наростаючою паузою (15, 30, 60, 120 с). Прогрес зберігається в базі, тож програму можна зупинити
й запустити знову — вона продовжить з місця зупинки.

## Де лежать дані

`C:\Users\<ім'я>\doaj-data\`
- `doaj.sqlite` — база (таблиця `journals`, у колонці `raw_json` — повний JSON журналу);
- `html\` — збережені сторінки журналів;
- `scraper.log` — журнал роботи програми.

## Запуск

Відкрити папку проєкту в IntelliJ IDEA, відкрити `src/main/java/ua/lnu/doaj/Main.java`, натиснути зелену
стрілку біля `main`.

Аргументи (необов'язкові): `journals` — тільки етап 1, `toc` — тільки етап 2,
`--refresh` — зібрати журнали заново.

## Структура коду

| Пакет / клас | Призначення |
|---|---|
| `model.*` | Java-моделі, що повторюють структуру JSON відповіді (згенеровані з допомогою LLM за зразком відповіді) |
| `http.DoajClient` | HTTP-запити, пауза між ними, заголовки, повтори, розпізнавання Cloudflare, зняття JSONP |
| `db.JournalRepository` | Робота з SQLite через JDBC: створення таблиць, UPSERT, прогрес |
| `scraper.JournalScraper` | Етап 1: збір усіх журналів |
| `scraper.TocDownloader` | Етап 2: завантаження HTML-сторінок |
| `Settings` | Усі налаштування в одному місці |
